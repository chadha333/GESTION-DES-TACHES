# Application Python de gestion des tâches

## Description

Application Python simple permettant de gérer des tâches quotidiennes
dans une interface texte (console).

## Fonctionnalités

- Ajouter une tâche
- Afficher les tâches
- Rechercher une tâche
- Quitter le programme

## Fichiers

- main.py : code de l'application
- README.md : documentation du projet

## Exécution

1. Ouvrir le projet dans VS Code.
2. Ouvrir le fichier main.py.
3. Cliquer sur "Run Python File".
4. Utiliser le menu du programme.

## Notions Python utilisées

- Variables
- Liste
- Conditions
- Boucle while
- Boucle for
- Fonctions
